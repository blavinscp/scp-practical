# SCP Practical Exams

This repo holds the hands-on practical exercises used for SCP Health Salesforce candidate interviews. Two tracks share the same scratch org and codebase:

| Track | Format | Doc |
|-------|--------|-----|
| **Developer** | ~1 hour, hands-on coding (Apex / Flow / LWC) | [`docs/DEVELOPER_PRACTICAL.md`](docs/DEVELOPER_PRACTICAL.md) |
| **Technical Architect** | 30 min, design + code review (no coding) | [`docs/ARCHITECT_PRACTICAL.md`](docs/ARCHITECT_PRACTICAL.md) |

Candidates: open the doc for your track and follow the instructions there. Interviewers: see `INTERVIEWER_NOTES.md` (gitignored) for the rubric and reference solutions.
